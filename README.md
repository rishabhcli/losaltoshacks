# Pilot Template

A frontend React application built with Vite, TypeScript, and Tailwind CSS. It is configured to integrate with Palantir Foundry's Ontology via the `@osdk/react` (Palantir OSDK).

## Prerequisites

- [Node.js](https://nodejs.org/) (>=22.9.0)
- [pnpm](https://pnpm.io/) (10.32.1 recommended)

## Installation

Install dependencies using pnpm:

```bash
pnpm install
```

## Running the Application

To start the development server locally, we recommend running it on port 3000:

```bash
pnpm run dev --port 3000
```

## Building for Production

To create a production build:

```bash
pnpm run build
```

To preview the production build locally:

```bash
pnpm run preview
```
